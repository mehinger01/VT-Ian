My Toolkit

Choose the right tool for the problem in front of you.

When I do not want to start

Five-minute start: define the smallest visible action and do only five minutes.

When the work is vague

Turn “study Chemistry” into a specific action with a clear done point.

When I get distracted

Notice → Name → Reset → Resume.

When I am reading

Before: map it. During: reduce it. After: retrieve, check, repair.

When I am studying

Hide the help → retrieve/solve → check → diagnose → repair → retry.

When something is big

Define done → milestones → dependencies → start dates → next visible action.

When everything feels urgent

Do, delay, ask, or consciously accept the consequence.

When the plan breaks

What changed? What still matters? What moves, shrinks, or needs communication?

Session Notes

Lightweight notes to carry useful evidence into the next meeting.
