MODULE 1

Algebra Mechanics

Goal: rebuild the algebra moves Algebra II will expect you to use without much hesitation.

1. Warm-up — no notes

a) 3x + 7 = 22
b) 5(x − 2) = 20
c) 4x + 3 = 2x + 15
d) x/3 + 5 = 9
Check answers
a) x = 5   b) x = 6   c) x = 6   d) x = 12

2. Core process

Simplify→Isolate→Check

Simplify: distribute and combine like terms. Isolate: use inverse operations to get the variable alone. Check: substitute your answer back into the original equation.

3(2x − 5) + 4 = 2(x + 7)
(2x − 1)/3 = 5
Check answers
First equation: x = 25/4 = 6.25. Second equation: x = 8.

3. Exponent rules refresh

Multiply same base

x³ · x⁴ = x⁷

Divide same base

x⁷ / x² = x⁵

Power of a power

(x³)² = x⁶

Zero exponent

x⁰ = 1

Negative exponent

x⁻² = 1/x²

Simplify: a) y⁵·y³   b) x⁹/x⁴   c) (m²)⁴   d) p⁻³
Check answers
a) y⁸   b) x⁵   c) m⁸   d) 1/p³

4. Independent finish

a) 2(3x + 4) − 5x = 17
b) 4(x − 3) + 2 = 2x + 8
c) Simplify (x⁴x³)/x²
Check answers
a) x = 9   b) x = 9   c) x⁵

Solid or rusty?

MODULE 2

Functions & Graphs

Goal: refresh the language Algebra II uses to describe relationships.

1. Retrieval warm-up

If f(x) = 2x + 3, find: a) f(4)   b) f(−2)   c) x when f(x)=11.
Check answers
a) 11   b) −1   c) x = 4

2. What function notation means

f(x) is another name for the output. Think: input → rule → output. The equation y = 2x + 3 and the function f(x) = 2x + 3 describe the same relationship.
For g(x)=x²−1, find g(3), g(0), and g(−2).
Check answers
g(3)=8, g(0)=−1, g(−2)=3.

3. Linear refresh

Remember y = mx + b: m is slope and b is the y-intercept.

a) Find the slope through (2,5) and (6,13).
b) Write the equation of a line with slope 3 and y-intercept −4.
c) In y = −2x + 7, identify slope and y-intercept.
Check answers
a) m = 2   b) y = 3x − 4   c) slope = −2, y-intercept = 7

4. Algebra II preview: function families

Linear

f(x)=2x+1

Constant rate of change.

Quadratic

f(x)=x²

Parabola; rate of change is not constant.

Exponential

f(x)=2ˣ

Repeated multiplication; growth can become very fast.

You do not need to master all three today. The key idea is that Algebra II studies different function families and how their graphs and equations behave.

5. Independent finish

Given h(x)=−3x+6: a) h(2)   b) h(−1)   c) solve h(x)=0   d) identify slope and y-intercept.
Check answers
a) 0   b) 9   c) x = 2   d) slope = −3, y-intercept = 6

Solid or rusty?

MODULE 3

Factoring & Quadratics

Goal: refresh the skill that becomes a major gateway in Algebra II.

1. Warm-up: distributive property backward

Factor: a) 3x + 12   b) 6x² + 9x
Check answers
a) 3(x+4)   b) 3x(2x+3)

2. Factor simple trinomials

For x² + bx + c: find two numbers that multiply to c and add to b.
a) x² + 5x + 6
b) x² + 7x + 12
c) x² − x − 12
Check answers
a) (x+2)(x+3)   b) (x+3)(x+4)   c) (x−4)(x+3)

3. Difference of squares

x² − 9 = (x−3)(x+3)

Pattern: a² − b² = (a−b)(a+b)

Factor: a) x² − 25   b) 4x² − 9
Check answers
a) (x−5)(x+5)   b) (2x−3)(2x+3)

4. Why factoring matters: solve a quadratic

x²+5x+6=0→(x+2)(x+3)=0→x=−2 or x=−3
Zero Product Property: if two factors multiply to zero, at least one factor must equal zero.
Solve: a) x² + 7x + 12 = 0   b) x² − 9 = 0
Check answers
a) x = −3, −4   b) x = −3, 3

5. Connect equation to graph

For y=x²+5x+6, the solutions x=−2 and x=−3 are also the x-intercepts—the points where the parabola crosses the x-axis.

If y=(x−1)(x+4), where does the graph cross the x-axis?
Check answer
x = 1 and x = −4, so the intercepts are (1,0) and (−4,0).

6. Independent finish

a) Factor x²+8x+15
b) Solve x²+8x+15=0
c) Factor x²−16
Check answers
a) (x+3)(x+5)   b) x=−3,−5   c) (x−4)(x+4)

Solid or rusty?
