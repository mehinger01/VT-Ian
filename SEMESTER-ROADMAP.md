# Ian — 19-Week / 38-Session Semester Roadmap

## Operating model

Two sessions each week. Real schoolwork is the preferred training environment.

**Session A — Run the Week:** workload scan, planning, priority, and the week's skill/upgrade.

**Session B — Execute + Learn:** real homework, practice, evidence review, and application with less coaching.

Each session has three lanes:
1. **Important homework** — real work overrides the prepared activity.
2. **Schoolwork, not urgent** — use current work while practicing the planned skill.
3. **No useful schoolwork** — run the prepared backup mission.

The recurring process is: **check reality → choose priority → define the next action → estimate → start → focus/recover → check evidence → adjust → commit.**

## Foundations already taught

- Five-minute start
- Visible next actions
- Prioritization
- Realistic focus blocks
- Phone/friend distraction management
- Notice → Name → Reset → Resume
- Before → During → After reading
- Closed-note retrieval
- Check → repair → retrieve again
- Todoist / assignment capture foundations

## Coaching progression

**Weeks 1–4:** control the workload.

**Weeks 5–8:** learn the work effectively.

**Weeks 9–12:** manage complex work and get help strategically.

**Weeks 13–16:** self-manage when school gets messy.

**Weeks 17–19:** transfer control to Ian.

## Rule for adaptation

Do not rewrite the curriculum simply because Ian brings different homework. Apply the current coaching target to the real assignment. Change the planned arc only when repeated evidence shows a different skill needs more time or a more urgent need has emerged.
